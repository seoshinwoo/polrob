# Chase Town — 실제 플레이용 타일 맵

기본 `GameMap`과 MAUI 게임 화면을 승인한 V7 에셋으로 전환했습니다. 경찰서/감옥, 카페·도넛·버거 상점가, 주택, 창고, 숲길을 유지하면서 타일 격자와 캐릭터 통행 폭에 맞춰 재배치했습니다. 캐릭터 에셋은 변경하지 않았습니다.

## 배경과 배치

- 월드: 2560×3840. 80×80 월드 단위 타일, **32열×48행 = 1,536칸**.
- 바닥: 기존 64×64 PNG 세 장(잔디·보도·도로)을 반복 사용. 큰 배경 이미지 로딩 없음.
- 렌더링: 카메라에 보이는 타일 범위만 순회. 도로는 4방향 이웃을 검사해 땅과 맞닿은 쪽만 연석 표시.
- 소품: 논리 에셋 중심 피벗, 월드 배율 2.5, 텍스처 밀도 6배. 같은 에셋을 재사용하며 화면 밖 소품은 그리지 않음.
- 상점가 양쪽의 남북 골목과 가로 샛길, 창고 옆 상자 우회로, 동쪽 숲길, 큰 순환도로를 연결.
- 예전 Canva 맵은 독립된 `canva-town-v1` 맵으로 보존. 메인 화면에서 선택하면 바로 재사용 가능. `new GameMap()`은 새 맵 사용. [두 맵 관리 안내](../map-management.md).
- 도로 `#484E57`, 일반 바닥 `#898B88`, 숲 구역 `#646F63`. 건물 구역은 콘크리트로 통일하고 오른쪽 아래 숲·상자·담장 구역은 회녹색으로 통일.
- 승인한 경찰서 주변/감옥 위/왼쪽 아래 집/도넛 가게/오른쪽 주택 사이 나무 제거와 통로 간격을 실제 배치에 반영. 창고 옆 상자 사이와 벽 옆은 연속 통행 검사 포함.

배치/타일 수정: `polrob.Shared/Models/ChaseTownLayout.cs`의 `CreatePlacements`, `CreateGround`.
렌더러: `polrob.Client/TownMapRenderer.cs`. 클라이언트와 아래 미리보기 도구가 같은 파일을 사용합니다.

## 판정과 기존 게임 규칙

- 건물 다각형은 `Buildings`, 나무 줄기·담장·상자·철창은 `Obstacles`에 등록. 이동 판정은 서버/클라이언트가 같은 데이터를 사용.
- 일반 건물 7종은 기존 윗쪽 판정에서 원본 8px(20 월드 단위)를 제외해 지붕 뒤로 캐릭터가 일부 가려짐. 앞·옆 판정과 그림 크기는 유지. [실제 렌더 비교](rear-clearance.png).
- 건물·담장·상자·줄기가 서버 체포 시야를 가림. 철창은 시야를 가리지 않음.
- 수풀은 이동을 막지 않고 `IsHidingArea`로 기존 은신 규칙에 연결. 자기 캐릭터가 가려지는 수풀/수관만 반투명 표시.
- 감옥 내부는 빈 공간이며 수감자를 holding 영역의 여러 줄에 겹치지 않게 배치.
- 구조는 감옥 앞 보라색 interaction 영역 진입으로 진행. 기존 구조 소요 시간과 석방 규칙은 유지하며, 석방 시 기존처럼 감옥 밖의 안전 위치로 이동. 열린 문 애니메이션/실제 문 개방 상태는 이번에 추가하지 않음.
- 지형 타일은 모두 통과 가능. 눈에 보이지 않는 보도/잔디 경계 장애물 없음.

이미지는 확인용 내보내기이며 게임이 배경으로 로드하지 않습니다. 확대 화면은 실제 캐릭터 PNG와 게임의 2배 카메라·몸통 크기·피벗을 사용합니다. 조작 UI·네트워크·시야 암전까지 포함한 단말 스크린샷은 아닙니다.

```sh
dotnet run --project tools/PolRob.TownMapPreview
dotnet test polrob.Server.Tests --no-restore
dotnet build polrob.Client -f net10.0-android --no-restore -p:RuntimeIdentifier=android-arm64
```

검증: 타일 도로 연결성, 역할별 안전 스폰, 주요 골목 연결(반지름 25/50), 모든 수풀 중심 접근, 감옥 구조 영역 접근, 수감 슬롯 비중첩, 기존 에셋/서버 회귀 검사. 미리보기 도구는 세 확대 구역에서 화면 밖 타일/소품 생략 전후 픽셀 일치도 검사합니다.

2026-09-22: **94개 테스트 통과**, Android arm64 Debug 빌드 성공(오류 0개; 기존 GameCreate XAML의 Frame/nullable 경고 8개).

같은 날 건물 뒤쪽 판정 보정 후 **102개 테스트 통과**. 이후 회색 배경·나무 제거·통로 컨셉을 타일 기반 런타임에 반영하고 두 맵 선택 기능을 추가했습니다. 이 전환에서 건물·나무 등 소품 PNG 16장의 SHA-256은 전후 동일하며, 배경 타일 3장만 회색 팔레트로 변경했습니다. 캐릭터 이미지와 승인한 뒤쪽 8px 판정 보정은 유지합니다.
