# PolRob 추격 맵 V2

> 이전 맵의 보관 기록입니다. 2026-09-09부터 실제 게임은 `CanvaMapLayout`과 `MapAssets`를 사용하며, 현재 결과는 [docs/town-map](../town-map/README.md)에 있습니다.

2560 × 3840 맵을 비대칭 동네 구조로 새로 구성했습니다. 첨부 이미지는 그림체와 높은 정면 시점의 기준으로만 사용했습니다. 실제 맵에 사용하는 건물·장애물·바닥 **19종은 전부 새로 생성한 파일**입니다.

## 맵 구성

- 북서쪽 경찰서·감옥: 경찰서 정면 도로와 숲을 통과하는 보행 경로로 진입합니다. 감옥 앞 구조·석방 공간을 확보했습니다.
- 중앙 시장: 두 시장 건물, 카페, 분수 사이로 서로 이어지는 골목을 배치했습니다. 큰 길로 나가거나 건물 사이에서 방향을 바꿔 돌아나올 수 있습니다.
- 동쪽 주거 구역: 시장 외곽 길과 남쪽 정비소를 연결하는 우회 경로입니다.
- 남동쪽 화물장: 창고와 큰 상자 더미를 돌아가는 경로, 창고 뒤편 보행 통로가 이어집니다.
- 숲 가장자리: 서로 다른 수관·크기·밀도의 나무 군락과 공터를 섞었습니다. 나무를 같은 간격으로 테두리에 줄 세우지 않았습니다.

도로 폭은 144–174 월드 단위입니다. 도로가 둘러싼 네 구역은 곡선 경계까지 paving.png로 가득 채우며, 도로 바깥은 잔디로 유지합니다. 개별 포장 조각과 흙길은 사용하지 않습니다. 바닥 자체는 걸을 수 있으며 건물과 주요 장애물이 실제 이동을 막습니다. 맵의 재미와 팀 간 균형은 실제 다인 플레이에서 추가 조정할 수 있습니다.

## 결과 파일

| 파일 | 용도 |
|---|---|
| `map-2560x3840.png` | 전체 맵 원본 크기 합성본 |
| `map-overview.png` | 1024 × 1536 전체 미리보기 |
| `background-2560x3840.png` | 잔디·구역 전체 벽돌 바닥·도로만 있는 배경 |
| `props-2560x3840.png` | 투명 배경의 건물·장애물 레이어 |
| `collisions-2560x3840.png` | 실제 공유 충돌 영역: 빨강 건물, 하늘색 장애물 |
| `detail-50px-characters.png` | 50 × 50 캐릭터를 넣은 1:1 상세 미리보기 |
| `layout.json` | C# 배치를 내보낸 좌표·크기·충돌 설정 |
| `asset-audit.json` | 런타임 이미지 크기·알파·실루엣 경계 검증 결과 |

게임은 합성 PNG 한 장을 그리는 방식이 아니라 반복 타일과 개별 스프라이트로 구성됩니다. 미리보기 도구도 게임과 같은 `TownMapRenderer`를 사용합니다.

## 새 에셋

런타임 폴더: `polrob.Client/Resources/Raw/TownMapV2/`

- 건물 8종: 경찰서, 은행, 감옥, 주택, 카페, 시장, 창고, 정비소
- 장애물 7종: 참나무, 자작나무, 덤불, 상자 더미, 가로등, 바위, 분수
- 256 × 256 바닥 4종: 잔디, 아스팔트, 보도 벽돌, 흙

원본을 `sources/`에 보관했습니다. built-in ImageGen으로 생성하고, 필요한 투명 배경 교정도 같은 도구로 수행했습니다. 크기 조절은 `sips`, 알파 검증과 미리보기는 SkiaSharp를 사용했습니다. 그림이 늘어나지 않도록 투명 여백을 제외한 실루엣의 비율로 배치 크기를 정했습니다. API/CLI 이미지 생성 대체 경로는 사용하지 않았습니다.

정확한 생성·교정 프롬프트:

## 게임 연결과 수정

`polrob.Shared/Models/TownMapLayout.cs`가 배치의 원본입니다. `Roads`에서 도로를, `Props`에서 위치·크기·충돌을 수정합니다. `TownMapRenderer.CreatePavedBlocks`가 도로 경로에서 닫힌 내부 구역을 계산해 벽돌로 채웁니다. 잔디 → 내부 구역의 벽돌 → 도로·연석 순서로 그립니다. `Groves`의 고정 시드로 나무 군락을 재현하므로 모든 클라이언트와 서버가 같은 충돌 배치를 사용합니다.

`Map.cs`의 기존 직사각형·원형 충돌 및 공간 인덱스를 사용합니다. 분수처럼 납작한 타원형 물체는 겹치는 원으로 감싸고, 건물·큰 상자는 직사각형으로 처리합니다. `GamePlay.xaml.cs`가 새 에셋을 로드하고, 서버 시작점도 같은 맵에서 장애물과 다른 플레이어를 피해서 정합니다.

현재 게임의 캐릭터 충돌 반지름 50(지름 100)은 유지했습니다. 요청한 50 × 50 크기 조건도 함께 검사합니다. 상세 PNG의 캐릭터는 요청한 50 × 50로 표시합니다. 캐릭터 자체의 에셋과 게임 규칙은 변경하지 않았습니다.

```sh
dotnet run --project tools/PolRob.TownMapPreview
dotnet test polrob.Server.Tests/polrob.Server.Tests.csproj --no-restore
dotnet build polrob.Client/polrob.Client.csproj -f net10.0-ios -r iossimulator-arm64 -t:Compile --no-restore
```

내보내기 도구는 이전 에셋 경로가 섞였거나 스프라이트에 실제 투명 배경이 없으면 실패합니다. 테스트는 원형·직사각형 충돌, 맵 경계, 시작점, 감옥 구조·석방, 시장 샛길과 창고 통로의 연결을 검사합니다. iOS Compile 검증은 앱 패키징·실기기 실행 검증과는 별도입니다.
