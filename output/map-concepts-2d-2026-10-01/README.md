- [원본 캐릭터 합성본](05-construction-left-with-characters.png).
- [내장 image_gen 편집 프롬프트](05-construction-left-prompt.md).

실제 캐릭터 PNG를 기존 게임 비율로 합성하고, 옮긴 구역의 빈 공간에 캐릭터가 놓이는지 확인했습니다. 게임 적용 전 미술 시안입니다.

## 연못·공사 구역·회색 도로 시안

비대칭 추격 마을의 오른쪽 중간 광장 중앙 나무를 단순한 연못으로 바꾸고, 전체 도로의 푸른 기를 줄여 중성 회색으로 조정했습니다. 오른쪽 아래 ㄱ자 창고를 비우고 흙바닥, 낮은 기초 구조물, 소수의 자재·임시 차단봉을 둔 공사 구역으로 바꿨습니다. 기존 작은 파란 건물은 현장 사무실 형태로 유지했습니다.

- [맵 원본](04-pond-construction.png): 1024 × 1536.
- [원본 캐릭터 합성본](04-pond-construction-with-characters.png): 기존 게임 비율로 경찰 2명·도둑 4명 배치.
- [생성 프롬프트](04-pond-construction-prompt.md): 내장 image_gen 사용.
- [캐릭터 합성 설정](04-pond-construction-preview.json).

원본 캐릭터를 직접 합성해 연못 우회 공간과 공사 구역 진입부를 시각적으로 확인했습니다. 지도 제작용 시안으로, 실제 충돌 및 게임 밸런스 검증을 수행한 런타임 지도는 아닙니다.

## 비대칭 추격 마을 — 구조 변경 시안

v2의 단순한 2D 표현과 에셋 형태를 참고해 배치를 재구성했습니다. 기존의 같은 크기 블록 반복을 상점 골목·열린 광장·길쭉한 공원·창고 마당으로 바꾸고, 좌측 상단 경찰서와 바로 옆 감옥을 유지했습니다.

- [맵 원본](03-dynamic-town.png): 1024 × 1536.
- [기존 경찰 2명·도둑 4명 합성본](03-dynamic-town-with-characters.png).
- [상점 골목 확대](03-dynamic-town-market-detail.png), [광장 확대](03-dynamic-town-square-detail.png).
- [생성 프롬프트](03-dynamic-town-prompt.md), [캐릭터 합성 설정](03-dynamic-town-preview.json).

도로·포장·잔디를 모두 걸을 수 있다는 기존 규칙을 전제로, 큰길 우회와 상점 사이·공원 횡단길·창고 마당의 내부 이동을 조합하도록 구상했습니다. 벽과 상자를 일부 추가하고 기존 지붕 표현의 ㄱ자 창고 및 직선 수풀을 넣었습니다. 길은 수평·수직으로 구성했습니다.

내장 image_gen으로 생성한 배치 시안이며, 기존 PNG의 픽셀을 그대로 잘라 배치한 결과는 아닙니다. 실제 캐릭터는 원본 PNG를 기존 게임 비율로 직접 합성했습니다. 시각적으로 반복 배치 해소, 구역 구분, 주요 연결과 캐릭터 간격을 확인했으며 실제 게임 충돌·시야·추격 밸런스 검증은 별도입니다.

## 개선 시안 v2

초기 시안을 바탕으로 지붕의 빈 액자 형태를 청회색·청록·산호색의 단순한 색면으로 바꾸고, 도로·보도·잔디의 색 관계와 건물·나무의 외곽 표현을 정리했습니다. 첫 개선본을 원본 캐릭터와 합성해 확인한 뒤 지붕의 겹 테두리, 강한 수목 그림자, 상점 배지를 줄이는 수정 생성까지 진행했습니다.

- [맵 원본](02-clean-blocks-v2.png): 1024 × 1536.
- [원본 경찰 2명·도둑 4명 합성본](02-clean-blocks-v2-with-characters.png): 실제 게임의 맵 대비 표시 비율 적용.
- [캐릭터 주변 확대본](02-clean-blocks-v2-character-detail.png): 맵과 캐릭터를 같은 비율로 확대한 비교 이미지.
- [생성·수정 프롬프트](02-clean-blocks-v2-prompt.md): 내장 image_gen 사용.
- [합성 설정](02-clean-blocks-v2-preview.json): 기존 compose-character-preview.swift로 재현 가능.

경찰서 좌측 상단·감옥 인접 배치와 직선·직각 경로를 유지했습니다. 실제 캐릭터 PNG를 수정 없이 합성하여 전체 지도와 확대 부분을 확인했습니다. 이 결과는 미술 시안이며, 타일 간격·통로 폭을 정확한 격자에 맞추는 작업과 개별 에셋 제작은 게임 적용 단계에서 필요합니다.

## 보존한 초기 시안

사용자가 선택한 초기 2D 맵 시안입니다. 경찰서는 좌측 상단, 감옥은 바로 오른쪽에 있습니다. 길과 도로는 직선·직각을 기본으로 구성했습니다.

- `02-clean-blocks.png`: 캐릭터 없는 맵 원본 (1024 × 1536).
- `02-clean-blocks-with-characters.png`: 기존 경찰 2명·도둑 4명을 실제 게임 비율로 합성한 전체 맵.
- `02-clean-blocks-character-detail.png`: 캐릭터 주변을 맵과 함께 5배 확대해 비교한 이미지.
- `prompts.md`: 이 초기 시안의 원본 생성 프롬프트.
- `02-clean-blocks-initial-preview.json`, `compose-character-preview.swift`, `preview-scaling.md`: 캐릭터 합성 설정·도구·배율 근거.

합성 재현: 저장소 루트에서 `swift output/map-concepts-2d-2026-10-01/compose-character-preview.swift output/map-concepts-2d-2026-10-01/02-clean-blocks-initial-preview.json` 실행.

현재 이미지는 맵 아트 시안입니다. 실제 게임에 적용하려면 타일 간격을 일정하게 맞추고 건물·나무·장애물 에셋 및 충돌 판정을 따로 구성해야 합니다. 게임에 사용 중인 에셋과 코드는 변경하지 않았습니다.
